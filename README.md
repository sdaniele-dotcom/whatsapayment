# What's a Payment

The consumer-facing mortgage site for **whatsapayment.com**.

What's a Payment is the brand. **Crush Mortgage Corp is the licensed entity**,
and it is the licensee that must be named wherever credit terms appear — which
is why `LICENSEE_LINE` in `src/lib/site.ts` prints in the footer of every page
and beside every payment figure, and why the flyers generated by the
`crushmortgage` repo carry the badge up top and the licensee along the bottom.

Static Next.js export. No database, no server, no keys.

## Running it

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # static export into ./out
```

## Deploying

Pushing to `main` builds and publishes to GitHub Pages
(`.github/workflows/deploy.yml`). `public/CNAME` holds the custom domain, so
the DNS records for whatsapayment.com need to point at GitHub Pages and the
domain has to be set in the repository's **Settings → Pages**.

No secrets are passed to the build. The calculator runs entirely in the
browser; nothing on this site reads or writes data.

## Before launch

- [ ] **Activate the contact form.** A static export has no server, so
      `src/components/ContactForm.tsx` posts to FormSubmit. It delivers
      nothing until the first POST's confirmation email is clicked at
      `info@crushmortgage.com`. Until then every submission falls back to
      showing the phone number and email address. Afterwards, replace the
      address in `site.formEndpoint` with the alias hash FormSubmit issues, so
      the inbox is not sitting in the page source for scrapers.
- [ ] **Settle the company NMLS.** `site.companyNmls` is `2332050`, taken from
      the brand guide, which prints it on its own sample flyer. The
      `crushit` repo's config disagrees — it records `169136` as the company
      NMLS and `2332050` as an individual loan officer's — and
      `crushmortgage/lib/env.ts` carries a comment noting that a compliance
      review assumed the latter. One of the three is wrong and it is not a
      judgement call for code to make.
- [ ] **Check the phone number.** `site.phone` is `(562) 256-5779`, matching
      the brand guide and the team data. `crushit/src/lib/site.ts` lists
      `(562) 317-6112`. Same question as above.

## Notes on the content

**The calculator shows no APR, deliberately.** APR folds in lender fees, which
vary by file. Deriving one from a rate alone produces a number that looks
authoritative and is wrong, and APR is precisely the figure borrowers use to
compare lenders. The page says what it does include, what it cannot know, and
how to get a real one — see `src/components/PaymentCalculator.tsx`.

**Every payment figure carries its rate, its date and its assumptions**, in
the panel beside it, per the brand guide. That is a rule about the figure
never travelling on its own, so if you add a surface that shows a payment, it
needs the same treatment.

**The team's names, NMLS numbers and photos** in `src/app/about/page.tsx` come
from the published team data on crushyourmarket.com. They are real licence
numbers; do not edit them casually.

## Brand

`src/components/Logo.tsx` serves the real marks, extracted from the brand
guide PDF rather than redrawn — the P is a custom glyph whose bowl and tail
read as a question mark, and no typeface reproduces it. The amber dot is part
of every mark and is never recoloured. Colour tokens are defined once in
`src/app/globals.css`; `.highlight` is amber behind navy text and never the
reverse.
